The form a matrix arrived in.

format::cpk::parse_directoryfn

Parses and checks the directory against its superblock: the hash, rows that tile 0..n_rows in order, and page-aligned, ascending, non-overlapping chunks after the superblock and before the directory.

format::cpk::parse_superblockfn

Parses a superblock (at least SUPERBLOCK_LEN bytes) and checks its fields against each other; the hash is checked by parse_directory .

format::cpk::ChunkEntrystruct

One chunk: rows first_row..first_row + n_rows at offset , len bytes of which the first meta_len are its metadata.

format::cpk::Superblockstruct

Decoded superblock fields.

format::RecordLayoutenum

How a record stores its elements.

format::parse_metafn

Parses metadata from the start of bytes (the metadata alone or a whole chunk). Checks the header and section sizes; per-cell table entries are checked where they are read.

format::record_nnzfn

Element count of a record from its header alone: the varint after the flags byte (0 for an empty record). For a sparse record it counts stored entries (explicit zeros included); for a dense record, non-zero values. A caller can compare it with metadata before committing to a decode.

format::Metastruct

Interpretation of a chunk’s metadata bytes. Holds no data of its own: header fields are decoded once, sections are borrowed.

format::OwnedMetastruct

Immutable metadata bytes and a validated descriptor. Views borrow only this owner; section offsets avoid self-referential pointers and lifetime extension.

loader::CONVERSIONSconstant

Classes in Conversion ’s numbering; the cost model’s table size.

loader::MAX_SCHEMASconstant

Most schemas one loader outputs.

loader::PROCESS_ABI_VERSIONconstant

The process ABI the loader implements: the layout of ProcessContext , CsrRow and DenseRow . A callback built against another version must not be passed to ProcessFn .

loader::PROCESS_BOUNDSconstant

Element-count boundaries of the process site’s size bands; a call’s element count (output dims for a dense record, stored elements otherwise) belongs to the band below the first boundary above it.

loader::REGION_ALIGNconstant

Alignment of each schema’s region within a slot.

loader::SLOT_ALIGNconstant

Alignment of slots.

loader::Acquisitionenum

Outcome of a bounded owned-lease acquisition.

loader::Conversionenum

Cost classes of conversions, as the cost model prices them.

loader::Errorenum

A loader failure.

loader::IoBackendenum

How a worker reads: the platform’s asynchronous ring, or blocking preadv.

loader::Planningenum

How a run caches.

loader::RowFormatenum

The row format a process function receives.

loader::allowedfn

Whether values stored as s may be output as t : the same type, lossless widening, same-width signed to unsigned (negatives are not checked), signed to wider unsigned, and any integer to a float.

loader::Batchstruct

Borrowed slot lease. Output references cannot outlive this guard.

loader::BatchLeasestruct

Owned slot lease, suitable for foreign-runtime array base objects.

loader::Countersstruct

Event counts every run keeps.

loader::CsrRowstruct

A CSR row: nnz stored elements with output columns in the chunk’s coded order (not sorted) and values of the schema’s dtype. Every other output dim is a zero or missing (see the module notes). A dense record delivered as a CSR row lists its non-zeros.

loader::DataSourcestruct

Every input matrix, numbered by global cell id, with each matrix’s map from its columns to the standard ids (the data side of the panel). Shared by planner and workers.

loader::DataSourceBuilderstruct

Registers matrices one at a time, then composes them into a DataSource .

loader::DenseRowstruct

A dense row: out_dim values of the schema’s dtype: the stored value or 0 at present dims, the schema’s default at missing dims (see the module notes).

loader::ExternAccessesstruct

A sequence computed by a native function.

loader::ExternCorpusAccessesstruct

A native corpus generator bound to the registered datasets’ row counts.

loader::IoStatsstruct

Read statistics of one worker, summed over workers in RunStats .

loader::Loaderstruct

One data source and the schemas that output its cells, ready to serve runs.

loader::LoaderConfigstruct

How a loader’s runs execute: threads, I/O backend, windowing and profiling.

loader::MemoryEstimatestruct

Bytes a run reserves, by purpose. Each term is a known reservation, not a measured footprint: allocator overhead, the compiler’s own state and the OS page cache are outside it, and reserved bytes need not be resident.

The module indexes enumerate every documented public item, including supporting enums, constants, traits and low-level helpers. Detail pages are regenerated from the crate source at build time. Public signatures, field types and method lists are therefore linked to the build, while semantic contracts are maintained in the module references.

Read contracts before composing layers ​

  • Representation: matrix inputs and dtype rules.
  • Sizes: shape, capacity, byte and workspace-word units.
  • Identity: column spaces, file rows, cells, positions and accesses.
  • Ownership: borrowing and concurrent use.
  • Failures: validation boundary and error variants.

Declarations, member links, implemented traits, and source excerpts come from the same build. Parameter explanations and worked examples add the usage context.
