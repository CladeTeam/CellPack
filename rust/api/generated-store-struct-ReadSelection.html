cellpack::store::ReadSelection ​

struct

Module contract · All interfaces

At a glance ​

pub struct ReadSelection { /* private fields */ }

Metadata prepared once for repeated reads into independently owned outputs. spec().nnz is the CSR capacity: the stored entries of the selected cells, which dropped genes can reduce in the result.

Prepare once, allocate from spec(), then read into your own buffers. Separate concurrent reads need separate mutable workspaces and outputs.

Try it ​

FIXED EXAMPLE RUST / CPU

Gather rows and map columns

Rows [3, 0, 3] preserve order and repetition. The source → output map keeps source column 2 first and column 0 second.

mod common;

use std::error::Error;
use cellpack::scans::UNMAPPED;
use cellpack::store::{CpkFile, ReadOptions, ReadWorkspace, RowSelection};

fn main() -> Result<(), Box<dyn Error>> {
    let file = CpkFile::open(common::fixture()?)?;
    let rows = [3, 0, 3];
    // Each entry maps a source column to its output position.
    let map = [1, UNMAPPED, 0, UNMAPPED];
    let selection = file.prepare_selection(
        RowSelection::List(&rows), Some(&map), 2, ReadOptions::default(),
    )?;
    let spec = selection.spec();
    let mut workspace = ReadWorkspace::default();
    let mut out = vec![0.0f64; spec.dense_len()?];
    selection.read_dense_into(&mut out, &mut workspace, 1)?;
    let mut offsets = vec![0u64; spec.rows + 1];
    let mut columns = vec![0u32; spec.nnz];
    let mut values = vec![0.0f64; spec.nnz];
    let nnz = selection.read_csr_into(
        &mut offsets, &mut columns, &mut values, &mut workspace, 1,
    )?;
    println!("rows: {rows:?}");
    println!("output: {out:?}");
    println!("CSR offsets: {offsets:?}");
    println!("actual nnz: {nnz}");
    Ok(())
}

pub fn read_dense_into<T: OutputElement>(
    &self,
    out: &mut [T],
    ws: &mut ReadWorkspace,
    workers: usize,
) -> Result<()>

Writes rows × columns values of T, converting from the stored dtype. Dimensions are validated before any I/O; codec or I/O failures may leave the output partially written. Chunks are split over up to workers threads, each with its own workspace scratch.

    &self,
    indptr: &mut [P],
    indices: &mut [I],

    ws: &mut ReadWorkspace,

Writes canonical CSR (ascending output columns per row) into caller arrays: indptr of rows + 1 entries, indices and values of at least ReadSpec::nnz entries. Rows are decoded at their capacity offsets, then compacted in place when genes were dropped; capacity past the returned nnz is unspecified. Dimensions and index widths are validated before any write. Returns the nnz.

Parameters ​

ParameterMeaning and constraints

wsExclusive reusable scratch for this call.
workersRead/decode worker count.

Result ​

Actual stored-entry count after mapping. Only this prefix of indices and values is meaningful; spec().nnz is an allocation capacity.
