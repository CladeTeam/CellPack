cellpack::loader::Ring ​

struct

Module contract · All interfaces

At a glance ​

pub struct Ring { /* private fields */ }

A bounded ring over owned or caller-provided memory: the slot protocol and the participant bookkeeping that keep one producer and world consumer ranks apart.

Construction either allocates (allocate, with_buffer) or takes caller-provided memory (init, init_regions, attach, attach_regions); the latter take raw pointers unsafely, and the constructors that accept an owner keep it alive through an Arc. _owned holds memory this value allocated, _owner retains a caller’s; both drop after every lease, since a lease keeps the Arc<Ring> it came from.

Allocate from loader.ring_layout so schema extents and alignment agree. All readers must release their leases before a slot can be reused. An aborted ring needs replacement.

Try it ​

FIXED EXAMPLE RUST / CPU

Deliver ordered batches

Two output schemas share each requested position. Missing dimensions use the schema default; present sparse zeros stay zero.

mod common;

use std::error::Error;
use std::sync::Arc;
use cellpack::loader::{
    DataSourceBuilder, Dtype, IoBackend, Loader, LoaderConfig,
    OutputSchema, Planning, Replicate, Ring,
};

fn main() -> Result<(), Box<dyn Error>> {
    let mut builder = DataSourceBuilder::new(5, 4096)?.direct_io(false);
    builder.add_cpk(common::fixture()?, &[0, 1, 2, 3])?;
    let source = Arc::new(builder.build()?);
    let schemas = vec![
        OutputSchema::dense(1, vec![3, 1, 4], Dtype::F32)?.with_default(f64::NAN),
        OutputSchema::dense(2, vec![0, 2], Dtype::F64)?,
    ];
    let loader = Loader::new(source, schemas, LoaderConfig {
        workers: 2, backend: IoBackend::Pread, slot_cells: 2,
        ..LoaderConfig::default()
    })?;
    let cells = [3u32, 0, 2, 3, 1];
    let accesses = Replicate::new(cells, 2)?;
    let ring = Arc::new(Ring::allocate(loader.ring_layout(2, 1))?);
    let run = loader.prepare(&accesses, ring, Planning::None)?;
    let stats = run.for_each_batch(|batch| {
        let panel: Vec<f32> = batch.region(0).chunks_exact(4)
            .map(|v| f32::from_ne_bytes(v.try_into().unwrap())).collect();
        println!("positions {}..{}: panel {panel:?}",
            batch.first_position(), batch.first_position() + batch.rows() as u64);
        Ok(())
    })?;
    println!("delivered: {} positions, {} accesses", cells.len(), stats.counters.accesses);
    Ok(())
}
OUTPUTExpected result
positions 0..2: panel [0.0, 8.0, NaN, 1.0, 2.0, NaN]
positions 2..4: panel [6.0, 0.0, NaN, 0.0, 8.0, NaN]
positions 4..5: panel [0.0, 0.0, NaN]
delivered: 5 positions, 10 accesses

Safety ​

Memory is exclusive during initialization, remains valid for this ring and its batches, and is accessed only through the slot protocol.

with_buffer ​

pub unsafe fn with_buffer(
    data: *mut u8,
    data_len: usize,
    layout: RingLayout,
    owner: Arc<dyn Send + Sync>,
) -> Result<Self>

Allocates control metadata and uses an external data array of at least RingLayout::data_min_bytes and at most RingLayout::data_bytes, aligned to at least 8 bytes. Regions start at REGION_ALIGN multiples within the array, so a 64-byte aligned array gives 64-byte aligned regions.

Safety ​

The array remains allocated without reallocation while owner is alive. No aliases may access filling slots; ready slots follow the lease protocol.
