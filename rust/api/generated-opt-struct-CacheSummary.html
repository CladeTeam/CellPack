At a glance ​

pub struct CacheSummary {
    pub page_uses: u64,
    pub distinct_pages: u64,
    pub hits: u64,
    pub misses: u64,
    pub capacity_pages: usize,
    pub row_hits: u64,
    pub output_hits: u64,
}

What a serial run of a trace did: its page uses, and the hits and misses a capacity produced.

capacity_pages: usize

Retention slots the run had, in pages.

row_hits ​

row_hits: u64

Accesses served by a cached mapped row; a page trace has none, so zero.

output_hits ​

output_hits: u64

Accesses whose output was already in the cache; a page trace has none, so zero.
