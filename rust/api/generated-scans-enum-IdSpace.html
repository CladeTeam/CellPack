cellpack::scans::IdSpace ​

enum

Module contract · All interfaces

At a glance ​

pub enum IdSpace {
    Source,
    Coded,
}

Borrowed inputs, selections and encoding options. Gene numbering of decoded indices.

Fields and variants ​

Source ​

Source

The input’s gene ids, ascending within each cell, with the input’s values: decoding reproduces the input exactly.

Coded ​

Coded

The chunk’s internal ids (frequency rank when renumbered), ascending, with their values. Records are stored in this order, so nothing is reordered; callers holding their own gene mapping compose it with the chunk’s gene order once per chunk. Equal to Source for chunks without renumbering.
