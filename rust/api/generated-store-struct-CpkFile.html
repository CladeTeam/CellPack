At a glance ​

pub struct CpkFile { /* private fields */ }

An opened .cpk file.

Use for file inspection and prepared reads. Prefer prepare_read or prepare_selection when you need typed output or reusable buffers.

Try it ​

FIXED EXAMPLE RUST / CPU

Write and reopen a matrix

Write a small matrix and inspect the decoded dense rows and CSR structure. The file becomes readable after finish succeeds.

mod common;

use std::error::Error;
use cellpack::format::{Dtype, SourceLayout};
use cellpack::scans::DenseRef;
use cellpack::store::{CpkFile, CpkWriter, ReadWorkspace};

fn main() -> Result<(), Box<dyn Error>> {
    let path = common::directory()?.join("example.cpk");
    let values = [0.0f32, 2.0, 0.0, 1.0, 0.0, 3.0];
    let bytes: Vec<u8> = values.iter().flat_map(|v| v.to_le_bytes()).collect();
    let mut writer = CpkWriter::create(
        &path, 3, Dtype::F32, SourceLayout::Dense, common::options(),
    )?;
    writer.append(DenseRef { n_genes: 3, value_width: 4, data: &bytes })?;
    writer.finish()?;

    let file = CpkFile::open(&path)?;
    let selection = file.prepare_read(0..2)?;
    let mut out = vec![0.0f32; selection.spec().dense_len()?];
    selection.read_dense_into(&mut out, &mut ReadWorkspace::default(), 1)?;
    let csr = file.read_csr(0..2)?;
    println!("shape: {} × {}", file.n_rows(), file.n_cols());
    println!("dense: {out:?}");
    println!("CSR offsets: {:?}", csr.indptr);
    println!("CSR columns: {:?}", csr.indices);
    Ok(())
}
OUTPUTExpected result
shape: 2 × 3
dense: [0.0, 2.0, 0.0, 1.0, 0.0, 3.0]
CSR offsets: [0, 1, 3]
CSR columns: [1, 0, 2]

prepare_selection ​

pub fn prepare_selection(
    &self,
    rows: RowSelection<'_>,
    gene_map: Option<&[u32]>,
    columns: usize,
    options: ReadOptions,
) -> Result<ReadSelection>

Prepares rows from metadata only; record bytes are read by each *_into call. gene_map sends each source column to an output column below columns (distinct targets) or drops it with UNMAPPED; without it, columns is the file’s column count.

Parameters ​

ParameterMeaning and constraints
rowsFile rows. A List preserves order and repeated IDs.
gene_mapOptional source-column → output-column map; one entry per source column. Use UNMAPPED to drop a column.
columnsOutput width in elements, including zero-filled missing output positions.
optionsRead policy and merge settings. These describe application reads, not physical device traffic.
