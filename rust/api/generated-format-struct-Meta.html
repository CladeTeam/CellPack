cellpack::format::Meta ​

struct

Module contract · All interfaces

At a glance ​

pub struct Meta<'a> { /* private fields */ }

Interpretation of a chunk’s metadata bytes. Holds no data of its own: header fields are decoded once, sections are borrowed.
